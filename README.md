Pasos:
- Abri la terminal en la primera carpeta "ProyectoEuler"
- Inicia el virtual enviorement
- "pip install -r requirements.txt"
- Ingresa la API KEY con: 
´´´
$env:GEMINI_API_KEY="[API KEY]"
´´´
- Haz: "cd ProjectEuler"
- Ejecuta el programa con: "py -u agente.py --desde [NUMERO EJERCICIO] --hasta [NUMERO EJERCICIO]"
(por ejemplo:"py -u agente.py --desde 9 --hasta 20" )
